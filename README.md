# HyperHire 🚀

> AI-Native Hyperlocal Workforce Operating System

HyperHire is a full-stack AI-powered workforce platform that connects businesses with skilled students and freelancers using semantic AI matching, real-time collaboration, and workflow automation.

Built during CODEFLOW 2026.

---

## 🌐 Live Demo

https://codeflow-2026-maruti-hyper-hire.vercel.app

---

## ✨ Features

### 👨‍🎓 For Students
- AI-powered job recommendations
- Portfolio showcase
- Smart application enhancement
- Trust score system
- Earnings dashboard
- Real-time messaging
- Workflow collaboration board

### 🏢 For Businesses
- AI talent discovery
- Semantic candidate matching
- Job posting & management
- Candidate pipeline tracking
- Hiring analytics
- Escrow-based payments

### 🧠 HyperAI Assistant
- Context-aware AI assistant
- Profile optimization
- Strategic AI suggestions
- AI quick actions
- Semantic confidence scoring

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Zustand

### Backend & Database
- Firebase Authentication
- Cloud Firestore
- Cloudinary

### AI Engine
- FastAPI
- Sentence Transformers
- scikit-learn
- NumPy

---

## 🧠 AI Matching System

HyperHire uses semantic embeddings and explainable AI ranking to intelligently match candidates with gigs.

### Matching Factors
- Semantic similarity
- Skill overlap
- Trust score
- Experience alignment
- Portfolio relevance
- Category preference

---

## 🏗️ Architecture

```txt
Frontend (Next.js)
       ↓
Firebase (Auth + Firestore)
       ↓
FastAPI AI Engine
       ↓
Sentence Transformer Model
```

## 🚀 Run Locally

### Frontend

```bash
npm install
npm run dev
```

### AI Engine

```bash
cd ai-engine
pip install -r requirements.txt
uvicorn main:app --reload
```
